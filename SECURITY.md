# Security

Please do not report security vulnerabilities in public issues or discussions.

Write to **support@kitloom.dev** with "Security" in the subject: what is affected (package, version, Filament or Nova), how to reproduce it, and what an attacker could do. You can also use [GitHub's private vulnerability reporting](../../security/advisories/new) on this repository.

We confirm receipt within two business days, keep you informed while we work on a fix, and credit you in the changelog if you wish, once the fix is released.
